字段过滤参数

参数名类型说明
response_model_exclude_unsetbool是否过滤掉未显式设置默认值的字段（返回更紧凑的 JSON）
response_model_exclude_defaultsbool是否过滤掉与默认值完全相同的字段
response_model_exclude_nonebool是否过滤掉值为 None 的字段
response_model_excludeset[str]显式指定要排除返回的字段名称集合
response_model_includeset[str]显式指定仅包含返回的字段名称集合
