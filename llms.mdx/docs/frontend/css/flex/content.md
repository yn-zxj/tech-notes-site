# Flex 弹性盒子 (/docs/frontend/css/flex)

## 概述 [#概述]

&#8195;&#8195;传统的布局解决方案，基于盒装模型，依赖`display`属性 + `position`属性 + `float`属性。它对于那些特殊布局非常不方便，比如，垂直居中就不容易实现。

&#8195;&#8195;2009 年，W3C 提出了一个新方案：Flex 布局，它可以简便、完整、响应式地实现各种页面布局。目前，它已经得到了所有浏览器的支持，这意味着，现在就能很安全地使用这项功能。
