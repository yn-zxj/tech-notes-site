依赖注入系统

依赖注入（Dependency Injection，简称 DI） 是 FastAPI 最核心的特性之一。它让开发者无需侵入业务代码，即可优雅地实现：

  • 共享业务逻辑（如分页、排序、过滤条件提取）
  • 共享数据库连接与 ORM 会话生命周期管理
  • 权限认证、OAuth2 登录与 JWT 令牌解析
  • 细粒度安全作用域（Security Scopes）
