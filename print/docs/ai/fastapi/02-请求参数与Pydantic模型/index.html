UploadFile vs bytes 选型建议

  • bytes：将整个文件一次性读入内存，仅适合几 KB 的微型文件。
  • UploadFile：基于 SpooledTemporaryFile，小文件在内存，超过限制自动写入硬盘临时文件，支持异步流式处理，是生产环境唯一推荐的文件上传方式。
